---

## 📖 Tentang Aplikasi

**PustakaPro** adalah aplikasi berbasis web yang dirancang untuk membantu sekolah, madrasah, perpustakaan desa, maupun perpustakaan umum dalam mengelola seluruh aktivitas perpustakaan secara digital.

Dengan tampilan yang sederhana dan modern, PustakaPro memudahkan petugas perpustakaan dalam mengelola data buku, anggota, transaksi peminjaman, hingga laporan secara otomatis.
